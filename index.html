How the SLA is counted

Open past target
Unresolved for more than 5 days at cut-off. Exactly 5 days is still on time.
Closure SLA
Closures within 5 days divided by all closures. Open tickets are not in this denominator.

Behind the reporting

How I build these views

My background is in banking operations. I build ClickUp workflows and Looker Studio reporting for service desks and branch teams. These public demos use fictional records, not internal tickets.

  1. 01
    Capture the workflow

    Record the branch, status, team, opening date and closure date in ClickUp.

  2. 02
    Make the rows comparable

    Use Google Sheets and Apps Script to align branch labels and status values. Keep missing owners visible.

  3. 03
    Make the totals explainable

    Define each service target and denominator. Keep the source rows available so managers can check the result.
