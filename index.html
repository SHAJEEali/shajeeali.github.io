About

Operations background, reporting focus

Process

How a project runs

  1. Discovery: Agree on the decisions the report needs to support.
  2. Data setup: Clean the source records and define each metric.
  3. Build and review: Test a working dashboard against real questions.
  4. Handover: Deliver the report, refresh setup and a short user guide.
